<objective>
Wrap each individual USDA lookup in logMeal with per-item error isolation so that any single item
throwing an error (network timeout, USDA API 5xx, parse failure) falls back to the usdaMatched=false
path instead of propagating the error to the outer Promise.all and aborting the entire meal save.

Purpose: Satisfy Phase 4 success criterion #4 — a food item with no USDA match (including due to
error) must not block the rest of the meal from being saved.

Output: app/lib/food.ts with a usdaMatchSafe() helper that wraps searchUSDA in a try/catch and
returns null on any error, used in place of the bare searchUSDA call inside logMeal.
</objective>
