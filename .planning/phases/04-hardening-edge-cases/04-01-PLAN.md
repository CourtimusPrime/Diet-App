<objective>
Audit NUTRIENT_ID_TO_COLUMN for any nutrientId keys that appear more than once (impossible in a JS
object literal but possible across dataset commentary) and add explicit deduplication logic inside
nutrientsToColumns() so that if USDA returns the same nutrientId for two semantically different
nutrients (e.g. ID 1278 appearing as palmitoleic in some datasets, EPA in others), the first
encountered value is kept and a warning is logged rather than silently overwriting.

Purpose: Prevent silent nutrient data corruption when USDA returns ambiguous IDs across Foundation
Foods vs SR Legacy datasets.

Output: app/lib/usda.ts with a DUPLICATE_NUTRIENT_IDS constant documenting known conflicts and
deduplication logic in nutrientsToColumns() using a seen-ids Set.
</objective>
