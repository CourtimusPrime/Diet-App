    Export async function POST(req: Request): Promise&lt;Response&gt;.

    Parse body: const { message } = await req.json(). If !message or typeof message !== 'string', return new Response(JSON.stringify({ error: 'message is required' }), { status: 400, headers: { 'Content-Type': 'application/json' } }).

    Create a ReadableStream with async start(controller):

    Step 1: const foods = await extractFoodItems(message). If foods.length === 0, enqueue a text chunk "I couldn't identify any food items in that message. Try describing what you ate more specifically." then enqueue '[DONE]' and close.

    Step 2: Parallel USDA lookups via Promise.all(foods.map(async (food) => { const usdaResult = await searchUSDA(food.name); return { food, usdaResult }; })).

    Step 3: Build foodItemsData array. For each { food, usdaResult }:
    - If usdaResult !== null: const columns = nutrientsToColumns(usdaResult, food.quantityG). Item: { name: food.name, quantityG: food.quantityG, quantityDisplay: food.quantityDisplay, usdaFdcId: usdaResult.fdcId, usdaDescription: usdaResult.description, usdaMatched: true, ...columns }
    - If usdaResult === null: Item: { name: food.name, quantityG: food.quantityG, quantityDisplay: food.quantityDisplay, usdaMatched: false }

    Step 4: const meal = await prisma.meal.create({ data: { description: message, foodItems: { create: foodItemsData } }, include: { foodItems: true } }).

    Step 5: Enqueue SSE chunk: encoder.encode('data: ' + JSON.stringify({ type: 'meal', meal }) + '\n\n').

    Step 6: Start second LLM call (streaming confirmation):
    - const confirmStream = await openai.chat.completions.create({ model: 'google/gemini-2.0-flash-001', stream: true, messages: [{ role: 'system', content: 'Write a brief, friendly 1-2 sentence confirmation of the meal just logged. Mention the foods.' }, { role: 'user', content: 'Logged: ' + meal.foodItems.map(f => f.name).join(', ') }] })
    - for await (const chunk of confirmStream): const text = chunk.choices[0]?.delta?.content ?? ''; if (text) enqueue encoder.encode('data: ' + JSON.stringify({ type: 'text', text }) + '\n\n')

    Step 7: Enqueue encoder.encode('data: [DONE]\n\n'). Call controller.close().

    Wrap entire start() body in try/catch: on error, log to console.error and call controller.error(err).

    Return new Response(stream, { headers: { 'Content-Type': 'text/event-stream', 'Cache-Control': 'no-cache', 'Connection': 'keep-alive', 'X-Accel-Buffering': 'no' } }).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → POST /api/chat | User-controlled message string enters server; must not be used as SQL or eval'd |
| OpenRouter API response → extractFoodItems | LLM output is parsed via JSON.parse; output shape is enforced by json_schema strict mode |
| USDA API response → nutrientsToColumns | Numeric field values only; unknown keys ignored |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Tampering | Prompt injection via meal description | mitigate | json_schema strict mode constrains LLM output to { foods: [...] }; LLM output is never eval'd or used in raw SQL; Prisma parameterises all queries |
| T-01-07 | Information Disclosure | OPENROUTER_API_KEY in server process | mitigate | Accessed via process.env only in route handler (server-side); Next.js never bundles server-only env vars into client JS |
| T-01-08 | Spoofing | LLM confirmation message rendered as HTML | mitigate | Client must render confirmation text as plain text — no dangerouslySetInnerHTML; instruction carried to Plan 01-04 |
| T-01-09 | Denial of Service | Unbounded message length | accept | Personal app, single-user; no auth surface; LLM context window is the natural limit |
| T-01-10 | Information Disclosure | Raw error details in HTTP response | mitigate | catch blocks log to console.error (server) and return generic error text to client; never expose stack traces |
| T-01-SC | Tampering | npm openai package | mitigate | openai@6.41.0 pre-audited in RESEARCH.md Package Legitimacy Audit; from github.com/openai/openai-node |
</threat_model>
