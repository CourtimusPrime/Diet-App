  <action>
    Create app/components/ChatInterface.tsx with 'use client' directive.

    IMPORTS (all from installed packages — no raw SVG):
    - { useState, useRef, useEffect } from 'react'
    - { Textarea } from '@/components/ui/textarea'
    - { Button } from '@/components/ui/button'
    - { Card, CardHeader, CardContent } from '@/components/ui/card'
    - { Badge } from '@/components/ui/badge'
    - { Collapsible, CollapsibleTrigger, CollapsibleContent } from '@/components/ui/collapsible'
    - { Separator } from '@/components/ui/separator'
    - { Send, ChevronDown, ChevronUp, Loader2, Utensils } from 'lucide-react'

    TYPES:
    Define FoodItem interface matching the Prisma FoodItem shape: id, name, quantityDisplay, usdaMatched, usdaFdcId (number | null), energy_kcal (number | null), protein_g (number | null), carbohydrate_g (number | null), fat_total_g (number | null), plus a catch-all [key: string]: unknown for expanded nutrient display.

    Define Meal interface: id, description, foodItems: FoodItem[].

    Define Message type as discriminated union:
    - { id: string; role: 'user'; content: string }
    - { id: string; role: 'assistant'; content: string }
    - { id: string; role: 'meal'; meal: Meal }

    COMPONENT ChatInterface:
    State:
    - messages: Message[] (useState([]))
    - input: string (useState(''))
    - isPending: boolean (useState(false))

    Refs:
    - bottomRef: useRef&lt;HTMLDivElement&gt;(null) — for scroll-to-bottom
    - textareaRef: useRef&lt;HTMLTextAreaElement&gt;(null) — for auto-resize

    Effect: useEffect watching messages — call bottomRef.current?.scrollIntoView({ behavior: 'smooth' }) when messages changes.

    TEXTAREA AUTO-RESIZE: useEffect watching input — set textareaRef.current.style.height = 'auto', then set to scrollHeight clamped between 40 and 120px.

    SUBMIT HANDLER (handleSubmit):
    - Guard: if (!input.trim() || isPending) return
    - Add user message to messages: { id: crypto.randomUUID(), role: 'user', content: input }
    - Clear input, setIsPending(true)
    - fetch('/api/chat', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ message: input }) })
    - Read response body via reader = response.body.getReader() + TextDecoder
    - Parse SSE stream: split by '\n\n', for each chunk starting with 'data: ':
      - Strip 'data: ' prefix
      - If chunk === '[DONE]': setIsPending(false), break
      - Parse as JSON: if (parsed.type === 'meal'): add { id: crypto.randomUUID(), role: 'meal', meal: parsed.meal } to messages
      - If (parsed.type === 'text'): append text to the last assistant message content (accumulate streaming text)
    - On fetch error: add error assistant message with copy from UI-SPEC Copywriting Contract: "Something went wrong logging that meal. Try again, or rephrase what you ate."
    - Finally: setIsPending(false)

    KEYBOARD HANDLER (handleKeyDown on Textarea):
    - if (e.key === 'Enter' && !e.shiftKey): e.preventDefault(); handleSubmit()
    - Shift+Enter: default textarea behavior (newline)

    FOODCARD COMPONENT (defined within the same file, not exported):
    Props: { item: FoodItem }
    Internal state: isOpen (useState(false))
    
    Render Shadcn Collapsible wrapping Shadcn Card:
    - Card header row: [dot] [name] [spacer] [kcalBadge] [chevronButton]
    - Dot: span with className="inline-block w-2 h-2 rounded-full flex-shrink-0" and conditional bg-green-500 (usdaMatched) or bg-zinc-400 (unmatched). Add title attribute: 'Matched in USDA FoodData Central' or 'No USDA match — nutrient data unavailable for this item' (per UI-SPEC Copywriting Contract)
    - Food name: span className="text-sm font-normal truncate flex-1 ml-2" (14px label role per UI-SPEC Typography)
    - kcal Badge: Shadcn Badge variant="secondary" showing energy_kcal value rounded to 0 decimals + ' kcal', or '— kcal' if null
    - ChevronDown/ChevronUp icon (16px) toggling isOpen; wrapped in CollapsibleTrigger; aria-label includes food name
    - Second row (always visible): macro pills inline row:
      - Protein: Badge className="bg-blue-100 text-blue-800 dark:bg-blue-900 dark:text-blue-200 text-xs" content: "P: {protein_g?.toFixed(1) ?? '—'}g"
      - Carbs: Badge className="bg-amber-100 text-amber-800 dark:bg-amber-900 dark:text-amber-200 text-xs" content: "C: {carbohydrate_g?.toFixed(1) ?? '—'}g"
      - Fat: Badge className="bg-red-100 text-red-800 dark:bg-red-900 dark:text-red-200 text-xs" content: "F: {fat_total_g?.toFixed(1) ?? '—'}g"
    - CollapsibleContent:
      - Separator
      - List of nutrient rows for all non-null numeric fields other than energy_kcal, protein_g, carbohydrate_g, fat_total_g
      - Each row: flex justify-between, label (human-readable from column name by replacing underscores with spaces and uppercasing first letter), value rounded to 2 decimals + unit suffix derived from column name suffix (_g → 'g', _mg → 'mg', _mcg → 'mcg', _kcal → 'kcal')
      - Only render rows where the value is a non-null number

    LAYOUT RENDER (ChatInterface return):
    Outermost: div className="flex flex-col h-screen bg-background"

    HEADER (sticky top): div className="sticky top-0 z-10 flex items-center h-14 px-4 border-b bg-background/95 backdrop-blur"
    - Utensils icon (lucide-react, 20px, className="mr-2")
    - span "NutriLog" className="font-semibold text-lg"

    SCROLL AREA: div className="flex-1 overflow-y-auto p-4 pb-20 space-y-4" (pb-20 = 80px scroll buffer above fixed input)
    - EMPTY STATE (when messages.length === 0 and !isPending):
      div centered with Utensils icon (48px, muted), h2 "Start logging" (text-xl font-semibold), p with UI-SPEC empty state body copy
    - MESSAGE LOOP: messages.map(msg => ...):
      - role 'user': div right-aligned, rounded card bg-zinc-100 dark:bg-zinc-800, max-w-[85%]
      - role 'assistant': div left-aligned, text-sm text-foreground, max-w-[85%]
      - role 'meal': div full-width, space-y-2, renders meal.foodItems.map(item => FoodCard)
    - TYPING INDICATOR (when isPending):
      div aria-live="polite" aria-label="Processing your meal" left-aligned:
      Three spans with className="w-2 h-2 bg-zinc-400 rounded-full animate-bounce" with staggered animation-delay (0ms, 150ms, 300ms via inline style)
    - div ref={bottomRef} (scroll target, zero height)

    FIXED INPUT BAR: div className="fixed bottom-0 left-0 right-0 z-10 border-t bg-zinc-100/95 dark:bg-zinc-900/95 backdrop-blur p-3"
    - Inner: div className="flex items-end gap-2 max-w-screen-sm mx-auto"
    - Textarea: ref={textareaRef}, value={input}, onChange={e => setInput(e.target.value)}, onKeyDown={handleKeyDown}, placeholder="What did you eat?", disabled={isPending}, rows={1}, className="flex-1 min-h-[40px] max-h-[120px] resize-none"
    - Button: type="button", size="icon", disabled={isPending || !input.trim()}, onClick={handleSubmit}, aria-label="Send message", className="h-11 w-11 flex-shrink-0" (44x44px touch target per UI-SPEC Accessibility Contract)
      - If isPending: Loader2 className="animate-spin h-5 w-5"

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSE stream → ChatInterface | LLM-generated confirmation text is rendered as plain text |
| User input → POST /api/chat | Input string is JSON-encoded; no XSS risk in the client component itself |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11 | Spoofing | LLM confirmation text rendered in chat | mitigate | Text rendered via React text nodes only (no dangerouslySetInnerHTML); LLM text cannot inject HTML |
| T-01-12 | Information Disclosure | API key visible in client bundle | mitigate | ChatInterface only calls /api/chat (same-origin); OPENROUTER_API_KEY and USDA_API_KEY are never referenced in client code |
| T-01-13 | Denial of Service | Rapid message submission while pending | mitigate | Send button and Textarea disabled when isPending=true; handleSubmit guard checks isPending before proceeding |
</threat_model>
