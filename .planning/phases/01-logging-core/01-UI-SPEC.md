## Spacing Scale

Declared values (multiples of 4, 8-point base scale):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, macro pill internal padding |
| sm | 8px | Pill horizontal padding, card internal gaps |
| md | 16px | Card padding, input area padding, message bubble padding |
| lg | 24px | Between food cards in message, section padding |
| xl | 32px | Bottom input bar height baseline padding |
| 2xl | 48px | Bottom input bar total reserved height (safe area) |
| 3xl | 64px | Scroll buffer above fixed input so last card is not obscured |

Exceptions:
- Touch targets for the send Button: minimum 44x44px (mobile accessibility requirement)
- USDA match dot: 8px diameter circle, vertically centered inline with food name

## Color

Palette: Shadcn New York default — zinc/slate scale. Light mode is default; dark mode is optional/secondary and not required for Phase 1.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` / `zinc-50` (`#fafafa`) | Page background, chat scroll area |
| Secondary (30%) | `zinc-100` (`#f4f4f5`) | Food cards (Card background), fixed input bar background |
| Accent (10%) | `zinc-900` (`#18181b`) | Send Button (primary action), focus rings |
| Destructive | `red-600` (`#dc2626`) | Not used in Phase 1 (no delete actions) |

Accent reserved for: **send Button only**. All other interactive elements use Shadcn default outline or ghost variants (zinc-based borders, no color accent).

Semantic overrides (not accent — these are data-visualization colors on Badge components only):

| Badge | Tailwind classes | Meaning |
|-------|-----------------|---------|
| Protein pill | `bg-blue-100 text-blue-800` | Protein grams |
| Carbs pill | `bg-amber-100 text-amber-800` | Carbohydrate grams |
| Fat pill | `bg-red-100 text-red-800` | Total fat grams |
| USDA matched dot | `bg-green-500` 8px circle | USDA FDC match confirmed |
| USDA unmatched dot | `bg-zinc-400` 8px circle | No USDA match found |
| kcal badge | Shadcn default secondary Badge | Kilocalorie count |

> Source: CONTEXT.md — "Macro pills: Protein (blue badge), Carbs (amber badge), Fat (red badge)" and "Green dot = USDA matched, grey dot = no match"

## Layout Contract

### Page Structure (mobile-first, 375px base width)

```
┌─────────────────────────────┐
│  Header (sticky top)        │ h-14, zinc-50 bg, "NutriLog" label
│  - App name / branding      │
├─────────────────────────────┤
│  Chat scroll area           │ flex-1, overflow-y-auto
│  - System/AI messages       │ Max-width 85% of viewport, left-aligned
│  - User messages            │ Max-width 85%, right-aligned, zinc-100 bg
│  - Food card groups         │ Full width within scroll area
│  - Typing indicator         │ Left-aligned, same position as AI messages
│  - 64px bottom buffer       │ Prevents last card hiding behind input
├─────────────────────────────┤
│  Fixed input bar (bottom)   │ fixed bottom-0, full width, zinc-100 bg
│  - Textarea (flex-1)        │ min-h-[40px] max-h-[120px], auto-resize
│  - Send Button (icon)       │ 44x44px touch target, accent bg
└─────────────────────────────┘
```

### Food Card Layout (collapsed state — default)

```
┌──────────────────────────────────────────┐
│ ● FoodName              [kcal] [▼]       │
│   [Protein: Xg] [Carbs: Xg] [Fat: Xg]   │
└──────────────────────────────────────────┘
```

- `●` = 8px dot: green (`bg-green-500`) or grey (`bg-zinc-400`)
- Food name: 14px weight-500 label
- kcal Badge: secondary variant, right-aligned before chevron
- 3 macro Badges: blue/amber/red as specified, inline row
- Chevron icon (lucide `ChevronDown`): toggles Collapsible

### Food Card Layout (expanded state)

```
┌──────────────────────────────────────────┐
│ ● FoodName              [kcal] [▲]       │
│   [Protein: Xg] [Carbs: Xg] [Fat: Xg]   │
├──────────────────────────────────────────┤
│  Vitamins                                │
│  Vitamin A    ........ 120 mcg           │
│  Vitamin C    ........ 8.4 mg            │
│  (etc — all non-null nutrient columns)   │
└──────────────────────────────────────────┘
```

- Separator between macro pills and expanded section
- Nutrient rows: 14px label (weight-400) + right-aligned value + unit
- Only display nutrient rows where the value is non-null

### Typing Indicator (while API pipeline runs)

- Three animated dots (CSS pulse or Tailwind `animate-bounce` staggered)
- Displayed in same position as AI message bubble (left-aligned)
- Shown from the moment POST /api/chat is fired until the response stream completes
- Replaced by confirmation text message once stream ends

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Enter key in Textarea | Submit message (preventDefault on Enter without Shift) |
| Shift+Enter in Textarea | Insert newline, do not submit |
| Send Button click | Submit message, same as Enter |
| Food card chevron click | Toggle Collapsible open/closed (default: closed) |
| Submit while pending | Disabled — send Button and Textarea disabled while API call in flight |
| Textarea auto-resize | Grows from 40px to max 120px as user types; shrinks on clear |
| New message arrival | Scroll chat area to bottom (smooth scroll) |
| Page load | Chat scroll area starts at bottom (most recent content visible) |

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Send Button touch target | min 44x44px (WCAG 2.5.5 AAA) |
| Send Button label | `aria-label="Send message"` |
| Typing indicator | `aria-live="polite"` region, `aria-label="Processing your meal"` |
| Food card toggle | `aria-expanded` on Collapsible trigger, `aria-controls` to content |
| USDA dot | `title` attribute with tooltip text as fallback |
| Color contrast | Shadcn New York defaults meet WCAG AA for all text on backgrounds |
| Macro pill contrast | Verify: blue-800 on blue-100, amber-800 on amber-100, red-800 on red-100 all meet 4.5:1 |
