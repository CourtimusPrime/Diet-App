The 3 tools to add (implement exactly as specified):

--- get_remaining_targets (MCP-03) ---
Tool name: 'get_remaining_targets'
Description: 'Compare todays consumed nutrients against your daily targets. Returns progress for each nutrient with a set goal.'
Schema: { date: z.string().optional().describe('Date as YYYY-MM-DD; defaults to today') }
Handler logic:
  1. const d = localDateStr(date)
  2. Parallel fetch: const [totals, targets] = await Promise.all([getDailyTotals(d), prisma.dailyTarget.findMany({ orderBy: { columnName: 'asc' } })])
  3. If targets.length === 0: return guidance message { date: d, message: 'No goals set. Use set_goal to define daily targets.', targets: [] }
  4. Map each target: { columnName, label, unit, target: t.targetAmount, consumed: totals[t.columnName] ?? 0, remaining: Math.max(0, targetAmount - consumed), percent: targetAmount > 0 ? Math.round((consumed / targetAmount) * 100) : 0 }
  5. Return { date: d, targets: result }

--- get_deficiencies (MCP-05) ---
Tool name: 'get_deficiencies'
Description: 'Return nutrients where todays intake is below 80% of the daily goal. Sorted by worst deficit first.'
Schema: { date: z.string().optional().describe('Date as YYYY-MM-DD; defaults to today') }
Handler logic:
  1. const d = localDateStr(date)
  2. Parallel fetch: const [totals, targets] = await Promise.all([getDailyTotals(d), prisma.dailyTarget.findMany()])
  3. If targets.length === 0: return guidance message { date: d, message: 'No goals set. Use set_goal to define daily targets.', deficiencies: [] }
  4. Filter: (totals[t.columnName] ?? 0) < t.targetAmount * 0.8   — DO NOT use goalStatus() — the 80% threshold is applied inline
  5. Map: { columnName, label, unit, target: t.targetAmount, consumed, percent }
  6. Sort ascending by percent (worst deficit first)
  7. Return { date: d, deficiencies }

--- get_nutrient_history (MCP-04) ---
Tool name: 'get_nutrient_history'
Description: 'Get per-day nutrient totals over a date range. Useful for spotting trends.'
Schema:
  - date: z.string().optional().describe('End date as YYYY-MM-DD; defaults to today')
  - days: z.number().int().min(1).max(30).optional().describe('Days to look back from end date; defaults to 7')
  - nutrients: z.array(z.string()).optional().describe('Specific nutrient column names to include; omit for all 103')
Handler logic:
  1. const endDate = localDateStr(date)
  2. const end = new Date(endDate)
  3. Loop i from (days-1) down to 0:
     - const d = new Date(end); d.setDate(d.getDate() - i)
     - const dateStr = d.toISOString().slice(0, 10)   — MUST use toISOString().slice(0,10) NOT toLocaleDateString()
     - const totals = await getDailyTotals(dateStr)
     - Push { date: dateStr, totals: nutrients ? Object.fromEntries(nutrients.map(k => [k, totals[k] ?? 0])) : totals }
  4. Return { endDate, days, history }

Return shape for all tools: { content: [{ type: 'text' as const, text: JSON.stringify(result) }] }
